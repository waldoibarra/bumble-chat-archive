# Bumble Chat Archive

These terms describe the conversation selected in Bumble Web and the saved archive.

## Language

**Match**:
The person whose selected Bumble Web conversation supplies the archive's match name.

**Conversation archive**:
The local record of one selected conversation's extracted messages and media download results.
_Avoid_: Full conversation

**Day separator**:
The conversation label that supplies a date for subsequent messages, without individual message times.
