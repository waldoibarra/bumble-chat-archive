# Bumble Chat Archive

Save a Bumble Web conversation's messages and available media locally for personal reference.
The scraper uses a browser session and asks you to select one conversation manually.

**Check the archive before relying on it.** Scrolling stops after repeated stable heights; missing messages remain possible.
Media downloads can also fail.

[Archive a conversation](docs/archive-conversation.md) for setup, the deletion warning, and output details.
See the [glossary](GLOSSARY.md) for terms used in the archive.
